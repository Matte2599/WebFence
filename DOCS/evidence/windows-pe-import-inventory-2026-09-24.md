## Italiano

**Verificato nella [CI `e4247b3`, sei job verdi](https://github.com/Matte2599/WebFence/actions/runs/35949425830).** Durante la costruzione dello ZIP, `objdump -p` legge l'eseguibile e ogni DLL, comprese le DLL dei plugin copiate da `windeployqt6`. `native-build.json` conserva `executable_imports` e la lista `imports` per ciascuna DLL già associata a hash, membro dell'archivio MSYS2, pacchetto e firma verificata. Sono nomi di import PE statici in minuscolo; `system_imports` distingue i nomi risolti dal sistema Windows o dalle famiglie API-set.

Il test sullo ZIP estratto confronta l'intero insieme dei file `.dll` con l'inventario, controlla gli hash, rifiuta import duplicati o senza DLL nel pacchetto/sistema registrato e stampa i percorsi Qt realmente distribuiti. Questo collega l'esame precedente di `PKGBUILD` e `.BUILDINFO` ai file che si trovano nel prodotto confezionato. La suite di **77 test Python** passa localmente e nella CI Windows; il test dello ZIP estratto passa con **43 DLL, 44 file PE, 22 pacchetti, 136 notices, 27 riferimenti Qt e 21 archivi sorgente**. Anche self-test e soak offscreen/Windows con PATH di solo sistema sono verdi. ZIP effimero della CI, non pubblicato: SHA-256 `2c286e5ecdd421dd4c48cd723a87d2c4f1c8c941850ed9a6d4032241c5382f46`.

I **15 file Qt** riportati dal test dello ZIP sono: `Qt6Core.dll`, `Qt6Gui.dll`, `Qt6Network.dll`, `Qt6Widgets.dll`, `generic/qtuiotouchplugin.dll`, `imageformats/qgif.dll`, `imageformats/qico.dll`, `imageformats/qjpeg.dll`, `networkinformation/qglib.dll`, `networkinformation/qnetworklistmanager.dll`, `platforms/qoffscreen.dll`, `platforms/qwindows.dll`, `styles/qmodernwindowsstyle.dll`, `tls/qcertonlybackend.dll`, `tls/qschannelbackend.dll`. `qjpeg.dll` è quindi distribuito e la sua dipendenza `libjpeg-8.dll` compare nella precedente lettura PE del pacchetto firmato; `qsqlite.dll` **non compare** nello ZIP di questa build, dunque l'opzione `system_sqlite` della ricetta non dimostra qui una dipendenza Qt SQL del prodotto distribuito. Questo non determina se l'eseguibile contenga altro codice SQLite. Gli altri import osservati in `Qt6Core.dll`/`Qt6Gui.dll` riguardano DLL presenti in questa build secondo il controllo di chiusura; gli hash delle DLL confezionate sono confrontati con i membri degli archivi firmati.

**Limiti:** un import PE statico non copre `LoadLibrary`, plugin caricati a runtime, codice incorporato staticamente o l'uso effettivo di un modulo. Il runner Windows Server 2022 e il suo ZIP di sviluppo non sostituiscono Windows 10/11 puliti; la mappatura non decide termini di licenza. `distribution_ready=false` e M0-02/06 restano invariati.

## English

**Verified in [CI `e4247b3`, six passing jobs](https://github.com/Matte2599/WebFence/actions/runs/35949425830).** During ZIP assembly, `objdump -p` reads the executable and every DLL, including plugin DLLs copied by `windeployqt6`. `native-build.json` retains `executable_imports` and an `imports` list for each DLL already bound to its hash, MSYS2 archive member, package and verified signature. These are lowercase static PE import names; `system_imports` distinguishes names resolved by Windows or the API-set families.

The extracted-ZIP trial compares the entire `.dll` file set with the inventory, checks hashes, rejects duplicate imports or imports without a recorded package/system DLL, and prints Qt paths actually shipped. This connects the earlier `PKGBUILD`/`.BUILDINFO` review to files present in the assembled product. The **77-test Python suite** passed locally and in Windows CI; the extracted ZIP passed with **43 DLLs, 44 PE files, 22 packages, 136 notices, 27 Qt references and 21 source archives**. Offscreen/Windows self-tests and soaks with a system-only PATH also passed. Ephemeral CI ZIP, not published: SHA-256 `2c286e5ecdd421dd4c48cd723a87d2c4f1c8c941850ed9a6d4032241c5382f46`.

The **15 Qt files** reported by the extracted-ZIP trial are: `Qt6Core.dll`, `Qt6Gui.dll`, `Qt6Network.dll`, `Qt6Widgets.dll`, `generic/qtuiotouchplugin.dll`, `imageformats/qgif.dll`, `imageformats/qico.dll`, `imageformats/qjpeg.dll`, `networkinformation/qglib.dll`, `networkinformation/qnetworklistmanager.dll`, `platforms/qoffscreen.dll`, `platforms/qwindows.dll`, `styles/qmodernwindowsstyle.dll`, `tls/qcertonlybackend.dll`, `tls/qschannelbackend.dll`. `qjpeg.dll` is therefore shipped and its `libjpeg-8.dll` dependency appears in the earlier PE reading of the signed package; `qsqlite.dll` **is absent** from this build's ZIP, so the recipe's `system_sqlite` option does not show a Qt SQL dependency of the shipped product here. This does not determine whether the executable contains other SQLite code. Other observed `Qt6Core.dll`/`Qt6Gui.dll` imports correspond to DLLs present in this build under the closure check; packaged DLL hashes are compared with signed archive members.

**Limits:** static PE imports do not cover `LoadLibrary`, dynamically loaded plugins, statically embedded code or actual module use. The Windows Server 2022 runner and its development ZIP do not replace clean Windows 10/11 desktops; this mapping does not determine license terms. `distribution_ready=false` and M0-02/06 remain unchanged.
