# Checksum pubblicati dei pacchetti Windows / Published Windows package checksums

[Sorgenti IT](../it/M0-WINDOWS-SOURCES.md) · [Sources EN](../en/M0-WINDOWS-SOURCES.md) · [Roadmap](../ROADMAP.md)

## Italiano

**Stato: controllo tecnico della provenienza, non verifica PGP o licenza.** Il 2026-09-24 i nomi e le versioni dei 22 pacchetti binari UCRT64 del [piano Windows conservato](windows-sources-2026-09-23/native-build.input.json) sono stati confrontati con le rispettive pagine ufficiali `packages.msys2.org`. Da ciascuna pagina sono stati letti URL dell'archivio e SHA-256 pubblicato. Tutti e 22 gli archivi originali sono stati scaricati via HTTPS dal mirror indicato, senza installarli o eseguirne il contenuto; gli SHA-256 ricalcolati coincidono. Totale: **55.884.975 byte**. Esempio: [Qt 6.11.2-2](https://packages.msys2.org/packages/mingw-w64-ucrt-x86_64-qt6-base). Il registro revisionato `packaging/windows/msys2-binary-lock.json` contiene per ognuno nome, versione, SHA-256 e pagina sorgente; SHA-256 del registro: `86b547894df059e3cb51bfcc1f8f3ca1584a03a579358844fa2e5277ecbd469c`.

Il packaging Windows ora fallisce se il pacchetto installato non è nel registro, se la versione cambia, se l'archivio nella cache differisce dal checksum pubblicato o se cambia l'insieme dei 22 proprietari delle DLL. Include il registro nello ZIP e lega il suo hash a `native-build.json`; la prova PowerShell dello ZIP estratto ricontrolla registro, versioni e hash già verificati in fase di build. Aggiornare il registro richiede un nuovo esame degli artefatti: gli aggiornamenti di pacman non vengono accettati implicitamente. Le 59 regressioni Python locali sono passate, incluso il rifiuto di versione, hash, proprietario e pagina sorgente non revisionati; i 22 archivi reali sono stati ricontrollati contro il nuovo registro. La CI Windows sul codice modificato è ancora da verificare.

Il checksum pubblicato rafforza il legame con l'artefatto MSYS2 esatto, ma **non** verifica la firma PGP del pacchetto, le otto firme upstream con `SKIP`, la completezza del codice incorporato o gli obblighi di licenza. Un'esplorazione dei nomi negli stessi archivi ha trovato 30 candidati di attribuzione non selezionati dallo ZIP: `AUTHORS.md` di pcre2 e, nel pacchetto Qt, 27 `qt_attribution.json` più due testi `_LICENSE` sotto i protocolli Wayland. Questi file non sono copiati come codice nel prodotto Windows; il loro rapporto con eventuali componenti incorporati resta da esaminare. `distribution_ready=false` rimane corretto.

## English

**Status: technical provenance check, not PGP or legal verification.** On 2026-09-24, the names and versions of all 22 UCRT64 binary packages in the [retained Windows plan](windows-sources-2026-09-23/native-build.input.json) were compared with their official `packages.msys2.org` pages. The published archive URL and SHA-256 were read from each page. All 22 original archives were downloaded over HTTPS from the listed mirror without installing or executing their contents; recomputed SHA-256 values matched. Total: **55,884,975 bytes**. Example: [Qt 6.11.2-2](https://packages.msys2.org/packages/mingw-w64-ucrt-x86_64-qt6-base). The reviewed `packaging/windows/msys2-binary-lock.json` records each name, version, SHA-256 and source page; lock SHA-256: `86b547894df059e3cb51bfcc1f8f3ca1584a03a579358844fa2e5277ecbd469c`.

Windows packaging now fails if an installed package is absent from the lock, its version changes, the cached archive differs from the published checksum, or the set of 22 DLL owners changes. It includes the lock in the ZIP and binds its hash to `native-build.json`; the extracted-ZIP PowerShell check rechecks the lock, versions and hashes already verified at build time. Updating the lock requires reviewing the new artifacts; pacman updates are not accepted silently. The 59 local Python regressions passed, including rejection of an unreviewed version, hash, owner and source page; all 22 real archives were rechecked against the new lock. Windows CI on the changed code remains pending.

The published checksum strengthens the link to the exact MSYS2 artifact, but **does not** verify the package's PGP signature, eight upstream signatures marked `SKIP`, embedded-code completeness or license duties. A filename survey of the same archives found 30 attribution candidates outside the ZIP selection: pcre2's `AUTHORS.md` and, in Qt, 27 `qt_attribution.json` files plus two `_LICENSE` texts under Wayland protocols. Those files are not copied as code into the Windows product; their relationship to any embedded components still needs review. `distribution_ready=false` remains appropriate.
