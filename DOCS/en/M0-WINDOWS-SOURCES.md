## Available procedure

`scripts/collect_windows_sources.py` collects MSYS2 source packages matching recipes identified in the Windows `native-build.json`. Requires Python 3.9+, zstd and curl 8.4+. The inventory is a trusted build input in a controlled directory; it does not accept instructions from targets or AI. The program neither executes recipes nor installs dependencies.

```sh
python3 scripts/collect_windows_sources.py \
  PATH/notices/native-build.json \
  /tmp/webfence-windows-source-materials

# Optional: --reuse-directory ARCHIVE_DIRECTORY or --zstd PATH
python3 -m unittest discover -s scripts/tests -p 'test_*.py' -v
```

The destination must be new. Output retains original archives, `PKGBUILD`, `.SRCINFO`, input inventory and a manifest with every regular member’s hash/path. `INCOMPLETE` remains until success; failures retain partial materials without publishing the final manifest. Reuse rechecks the archive. There is no automatic Windows package attachment.

For each version, the collector compares the `PKGBUILD` SHA-256 against the binary package’s `.BUILDINFO`, previously matched against distributed DLLs. It deduplicates binary packages generated by the same recipe and rejects conflicting hashes. It checks `.SRCINFO` identity/version and declared checksums for generic and x86-64 sources; other architectures are not claimed as verified. `.SRCINFO` is read from the archive, not regenerated by executing `PKGBUILD`: checks establish correspondence to that metadata, not independent authentication or a binary rebuild.

URLs are fixed to `repo.msys2.org/mingw/sources`; HTTPS only, including redirects, without personal `.curlrc`. At most 64 packages, 256 MiB per archive, 1 GiB combined; 100,000 members and 2 GiB declared per archive, 1 MiB per metadata file. Streaming reads, no general extraction or followed links. Unsafe paths, duplicate members, wrong hashes and exceeded budgets stop collection. Transfers use the macOS collector’s redirect/time/stall limits.

VCS inputs remain `vcs_unverified`; signatures with `SKIP` and weak checksums remain `no_strong_checksum`. SHA-1/MD5 may be compared but cannot establish `verified` alone. Outer archive hashes are observed, not checked against independent signatures. `distribution_ready` and `corresponding_sources_complete` remain **false**.
