# M3 — Linux CDP lab with HTTP origin

[Italiano](../it/M3-BROWSER-CDP-LAB.md) · [ADR-016](ADR-016-LINUX-CDP-TRIAL.md) · [ADR-017](ADR-017-CDP-BROKER-BOUNDARY.md) · [M3 status](M3-VALIDATION.md)

`experiments/m3-cdp-browser` is an optional Linux fixture, not a GUI feature. It needs Go, Docker and Chromium **only inside the trial container**. It accepts no URL or external target. The parent creates a synthetic project/run and loopback target, binds scope/path and budgets to the gate and broker with a pinned IP, opens eight connections to the authenticated Unix proxy and passes them to the helper. The helper applies limits and seccomp before starting Chromium. CDP uses inherited pipes; every intercepted request is served through the proxy on preconnected sockets. The page `http://site.test:<port>/app/` loads a script, calls `fetch('/app/api')`, requests an outside image and reaches an endpoint redirecting outside the origin. The gate blocks the image; the broker stops the redirect; the target sees only four admitted requests. The program also checks events, counts, redacted observations, inherited filtering and protocol limits.

Linux AMD64 CI trial and local ARM64 trial on September 27, 2026: build with `CGO_ENABLED=0 go build -tags=m3cdplab -o /tmp/webfence-m3-cdp ./experiments/m3-cdp-browser`; build the image with `docker build -f experiments/m3-cdp-browser/Dockerfile -t webfence-m3-cdp-lab .`; run the binary mounted as `/wf-cdp` in the container without networking, read-only, with temporary `/tmp`, user 1000, `--cap-drop ALL`, `--security-opt no-new-privileges`, `--memory 1g` and `--pids-limit 256`. The complete versioned command is in the `m3-cdp-lab-linux` CI job. Forty local ARM64 repetitions passed with these limits; with 128 PIDs, one repetition exhausted threads while starting Chromium. Branch and `main` CI need separate checks.

The trial preserves HTTP origin in browser requests and denies autonomous networking on this experimental path. It does **not** test HTTPS or login or prove a safe sandbox for untrusted pages: Chromium uses `--no-sandbox` here only, the container is part of the trial boundary, and browser filesystem access is not mediated. Revocation during navigation, aggregate quotas outside the container, other OSs, the GUI and the first M3 item remain open.
