**macOS App Sandbox trial, September 29, 2026:** the ad hoc bundle without network entitlement denies a connection to a local listener on an OS-assigned port. Local Google Chrome, started as a headless child with its profile in the app container, exits with `abort trap` before the CDP response. The trial source and script are versioned; there is no positive macOS browser trial or demonstrated explanation for the abort. The command exits with code 1 as expected for the negative outcome. No external target was contacted.

**Windows AppContainer trial, September 29, 2026:** on Windows Server 2022 CI, the child confirms an AppContainer token without network capabilities; an unrestricted control reaches the system-assigned loopback listener while the child times out. Assignment to the configured Job Object succeeds. This does not test a browser, Internet egress, limits under load or Windows 10/11; the first criterion remains open.

Credentials, URLs, queries, headers and bodies are absent from the redacted results of these blocks; GUI passwords are not saved, but Go, Qt or OS copies may remain in memory. No finding, or a different response, does not prove that access control is correct. GET can have effects: local fixtures do not authorize external trials.
